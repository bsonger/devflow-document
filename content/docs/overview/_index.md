# 🛰️ 平台概览

## DevFlow 能帮你做什么

DevFlow 是一个**云原生应用交付平台**。简单说，它帮你把代码变成运行在生产环境的应用，并且让整个过程中所有环节都可控、可观测、可回滚。

这篇文档适合想先回答两个问题的读者：

1. **DevFlow 解决什么问题？**
2. **它的能力边界在哪里？**

### 一个典型的发布日

**没有 DevFlow 时：**

> 小明要发布支付服务的新版本。他改了配置文件，但忘了把测试环境的数据库地址换成生产环境的。镜像构建完后，他手动写了 Kubernetes YAML，然后 `kubectl apply`。Pod 起来了，但小明不敢走，一直盯着 Grafana。后来他发现流量切换有问题，想回滚却不知道上一个版本是什么。折腾了 3 个小时，凌晨 1 点才回家。

**有了 DevFlow 时：**

> 小明在 DevFlow Console 上点了"发布"，选择了新版本和目标环境。DevFlow 自动冻结了当前配置，触发了 CI 构建，把配置打包推送到集群。Canary 灰度从 10% 流量开始，小明看了 5 分钟监控指标，没问题就点了"继续"。30 分钟后发布完成，小明正常下班。

这就是 DevFlow 的价值 — **让发布从一件提心吊胆的事，变成一件可预期的事**。

## 🚫 DevFlow 不替你做什么

为了避免把平台边界说得过大，这里先明确几件事：

- DevFlow **不替代你的源码仓库**，它消费 Git 仓库中的代码和版本
- DevFlow **不替代 Kubernetes**，它是面向 Kubernetes 的交付控制面
- DevFlow **不替代应用监控系统**，而是把发布过程和现有观测体系串起来
- DevFlow **不消除发布风险**，它的目标是让风险更可控、更可观测、更易回滚

## ✨ 五大核心能力

### 1. 🗂️ 统一管理应用元数据

所有应用的信息集中在一个地方：

- 项目（Project）— 业务域维度，比如"支付系统"
- 应用（Application）— 单个服务，比如"支付网关"
- 环境（Environment）— 运行环境，比如"测试环境"
- 集群（Cluster）— Kubernetes 集群

不用再去各个系统的后台翻配置，一个平台全搞定。

### 2. 🧱 配置分层管理，环境差异不串台

同一套应用在不同环境跑，最大的坑就是**配置串台** — 把测试环境的数据库地址带到生产。

DevFlow 把配置分成两层：

- **WorkloadConfig（应用级基线）** — 不随环境变化的东西，比如副本数、探针、资源限制
- **AppConfig（环境级差异）** — 随环境变化的配置来源和挂载内容

发布时自动叠加，测试环境用测试配置，生产环境用生产配置，**永远不会串**。

### 3. 🚦 三种发布策略，按需选择

不是所有发布都需要同样的谨慎程度。DevFlow 提供三种策略：

| 策略 | 适合场景 | 特点 |
|------|---------|------|
| **Rolling** | 内部工具、低优先级服务 | 成本低，简单直接 |
| **Canary** | 核心 API、用户-facing 服务 | 先给少量用户试用，验证没问题再扩大 |
| **Blue-Green** | 金融核心、必须零停机 | 两套实例并行，瞬时切换 |

选对策略，既安全又不浪费资源。

### 4. 🧊 不可变快照，随时回滚

每次发布，DevFlow 都会保存两份快照：

- **Manifest** — 构建时刻的应用状态（代码版本、镜像、基础配置）
- **Release** — 部署时刻的完整状态（Manifest + 环境配置 + 发布策略）

这两份快照都是**不可变的**。出了问题，一键回滚到任意历史 Release，**完全可重现**。

### 5. 👀 实时观察发布进度

不用自己写脚本去 `kubectl get pods` 看状态。DevFlow 的 runtime-service 实时从 Kubernetes 抓取 workload 和 pod 的状态，直接展示在界面上：

- 当前在哪个发布阶段
- 有多少 Pod 已经 Ready
- 有没有异常事件

发布进度一目了然。

## 🛠️ 技术栈

DevFlow 本身跑在 Kubernetes 上，跟云原生生态紧密集成：

| 🧭 用途 | 🔧 选型 |
|------|------|
| 平台服务 | Go + Gin |
| 数据库 | PostgreSQL |
| CI 引擎 | Tekton Pipeline |
| CD 引擎 | Argo CD + Argo Rollouts |
| 流量治理 | Istio |
| 制品存储 | 📦 OCI Registry |
| 可观测性 | OpenTelemetry + Prometheus + Grafana |
| 运行平台 | {{< brand-icon name="kubernetes" alt="Kubernetes" >}} Kubernetes |
